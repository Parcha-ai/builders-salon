# Series identity

The Builders’ Salon, by **Parcha Labs and Piloto 151**.

The identity uses JetBrains Mono throughout, with a B constructed from polygon contours, a 32 / −32 extrusion, and visibility-tested wireframe edges.

## Assets

Every asset is available as SVG and 2× PNG in [assets/](assets/).

| File stem | Use |
| --- | --- |
| `builders-salon-logo` | Full wordmark on warm paper |
| `builders-salon-transparent` | Ink wordmark and vermilion B, transparent background |
| `builders-salon-reverse` | Paper wordmark and vermilion B on ink |
| `builders-salon-white` | Paper-colored wordmark and B, transparent background |
| `b-mark` | Vermilion B, transparent background |
| `b-mark-paper` | Vermilion B on warm paper |
| `b-mark-white` | Paper-colored B, transparent background |

SVGs contain paths rather than live text or linked images. Transparent versions have transparent counters as well as transparent backgrounds.

## Design values

| Element | Value |
| --- | --- |
| Paper | `#F4F0E7` |
| Ink | `#20221F` |
| Vermilion | `#D74327` |
| Wordmark | JetBrains Mono SemiBold; both lines at the same size |
| Supporting type | JetBrains Mono Medium |

The [Event 001 generator](../events/001-building-with-ai/artwork/generate.py) creates this initial identity alongside the flyer. Run `make build` from the repository root to regenerate both.
