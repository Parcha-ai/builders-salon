# JetBrains Mono

Unmodified font files from the [JetBrains Mono project](https://github.com/JetBrains/JetBrainsMono):

- `JetBrainsMono-Medium.ttf`: supporting type and source-code background.
- `JetBrainsMono-SemiBold.ttf`: the series wordmark and event headline.
